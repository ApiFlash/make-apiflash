# ApiFlash

[ApiFlash](https://apiflash.com) is a screenshot API built on top of Chrome running on AWS Lambda. It renders web pages exactly like a desktop browser and captures screenshots at scale.

This app lets you capture screenshots of any website directly from your Make scenarios. The captured image is returned both as a file (ready to be mapped into Dropbox, Google Drive, email or any other file-consuming module) and as a URL to the cached screenshot.

To use this app, you need an ApiFlash access key. You can create a free account and find your access key in the [ApiFlash dashboard](https://apiflash.com/dashboard/access_keys).
